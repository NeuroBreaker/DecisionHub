# 🏆 DecisionHub

**Платформа для проведения хакатонов** — автоматическая проверка артефактов команд, оценка жюри с настраиваемыми весами и живой лидерборд.

Проект сделан в рамках хакатона. Поддерживает три роли: участник, эксперт жюри, организатор.

---

![Лидерборд](docs/leaderboard.png)

---

## ✨ Что умеет

**👤 Участник**
- Сдаёт артефакты: Git-репозиторий, документацию (PDF/DOCX), презентацию (PPTX), скринкаст (YouTube/VK Видео)
- Видит статус автопроверки в реальном времени

**🗂 Организатор**
- Настраивает веса критериев оценки
- Следит за прогрессом проверки команд
- Экспортирует итоговую таблицу в CSV

**⚖️ Жюри**
- Оценивает команды по 10 критериям (полнота MVP, качество кода, UX, документация и т.д.)
- Итоговый балл считается как взвешенная сумма: авто-оценка + экспертная

**🤖 Автопроверка**
- Статический анализ кода: LOC, цикломатическая сложность, поиск секретов через regex
- Анализ PDF/DOCX: структура, объём, наличие разделов
- Валидация ссылок на видео (YouTube / VK Видео)

## 🚀 Быстрый старт

```bash
docker-compose up -d --build
```

Приложение будет доступно на `http://localhost/`.

---

## 💻 Локальный запуск

### 1. PostgreSQL

Создайте базу данных и добавьте строку подключения в `.env` в корне проекта:

```env
DATABASE_URL=postgresql+asyncpg://USER:PASSWORD@localhost:PORT/DBNAME
```

### 2. Backend

```bash
cd backend
uv run src/main.py
```

### 3. Frontend

```bash
cd frontend
npm install
npm run dev
```
